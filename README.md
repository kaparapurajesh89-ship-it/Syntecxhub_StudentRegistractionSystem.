# Syntecxhub_StudentRegistractionSystem.
📚 Student Registration System The Student Registration System is a simple Java-based console application integrated with MySQL database. It allows users to perform basic CRUD (Create, Read, Update, Delete) operations on student records efficiently.

This project is designed to demonstrate how Java connects with a database using JDBC and how data is managed in real-world applications.

🚀 Features ➕ Add new student details 📄 View all student records ✏️ Update existing student information ❌ Delete student records 🔗 MySQL database connectivity using JDBC 🛠️ Technologies Used Java (Core Java) JDBC (Java Database Connectivity) MySQL Database Command Line Interface (CLI)
